# Kei000001.github.io

Source of my tech blog, published with GitHub Pages (Jekyll + minima).

- Site: https://kei000001.github.io

## Writing a post

1. Copy `_drafts/post-template.md` to `_posts/YYYY-MM-DD-short-title.md`.
2. Set `title`, `date`, and one category: `robotics`, `agents`, `imaging`, `papers`, or `kaggle`.
3. Keep the structure: Goal / Setup / What I Tried / Results / Lessons Learned / Links.
4. Put images in `assets/images/YYYY-MM-DD-short-title/`.
5. Add notable work to `projects.md`.
6. Push. The post is live in 1–2 minutes.

Files in `_drafts/` are not published.

## Before publishing — checklist

- [ ] Nothing related to my employer's work or confidential information
- [ ] Competitions (e.g. PARC2026, Kaggle): the rules allow sharing methods, code, and data at this time
- [ ] Courses (e.g. Physical AI course): no course materials, assignment texts, or model answers are reproduced
- [ ] Books: no long quotes of text or code; the book is credited
- [ ] Papers: the original paper and code license are credited; my own changes are clearly separated
- [ ] No API keys, tokens, or personal data in code or screenshots
